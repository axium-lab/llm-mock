Gemini Enterprise · Endpoints

Google renamed Vertex AI to the Gemini Enterprise Agent Platform. It serves the same model family as AI Studio through a different contract, under the /gemini-enterprise prefix. Both v1beta1 — the SDK's default here — and v1 are served.

MethodPathNotes
POST…/publishers/google/models/{model}:generateContentSame contract as AI Studio, plus a createTime on every response
POST…/publishers/google/models/{model}:streamGenerateContentSSE with ?alt=sse, streamed JSON array without it
POST…/publishers/google/models/{model}:predictEmbeddings — this platform has no :embedContent
POST…/publishers/google/models/{model}:countTokensReports totalTokens only
GET/gemini-enterprise/v1beta1/publishers/google/modelsPublisher catalog, nested under publisherModels
GET/gemini-enterprise/v1beta1/publishers/google/models/{model}versionId rather than version, and no token limits
POST/gemini-enterprise/v1beta1/interactionsInteractions API, same contract as AI Studio's

Every model path comes in two shapes, and the same handler answers both: the regional one, which production code uses, and the express one.

# regional — OAuth, project and location in the path
/gemini-enterprise/v1beta1/projects/{project}/locations/{location}/publishers/google/models/{model}:generateContent

# express — API key, no project or location
/gemini-enterprise/v1beta1/publishers/google/models/{model}:generateContent
There is no Files API here, and that is the platform's doing rather than a gap in the mock: @google/genai refuses the upload client-side with "Gemini Enterprise Agent Platform (previously known as Vertex AI) does not support uploading files. You can share files through a GCS bucket."

Gemini Enterprise · Two auth modes

Both are accepted against the same key set. Express mode takes an API key and addresses publisher models directly — it is by far the easier one to point at a mock:

const ai = new GoogleGenAI({
  vertexai: true,
  apiKey: "sk-mock-key-01",
  httpOptions: { baseUrl: "http://localhost:3000/gemini-enterprise" },
});

Regional mode is how production code calls the platform — an OAuth token, and projects/{p}/locations/{l} in every path. The SDK will not emit a request without Application Default Credentials, so pointing it at a mock means handing it something that answers like an auth client:

const ai = new GoogleGenAI({
  vertexai: true,
  project: "my-project",
  location: "europe-west1",
  httpOptions: { baseUrl: "http://localhost:3000/gemini-enterprise" },
  googleAuthOptions: {
    authClient: {
      getRequestHeaders: async () => new Headers({ authorization: "Bearer sk-mock-key-01" }),
      getAccessToken: async () => ({ token: "sk-mock-key-01" }),
      request: async () => ({ data: {} }),
    } as never,
  },
});

A rejection differs by transport, matching the platform: a bad OAuth token is 401 UNAUTHENTICATED, a bad API key 400 INVALID_ARGUMENT.

Unlike the AI Studio provider, none of this provider's shapes could be checked against the live service — that needs a GCP project with the platform enabled. Its routes come from observing what the official SDK puts on the wire, and its wire shapes from the SDK's own transformers, but its error messages and codes are inference rather than observation.

Gemini Enterprise · Embeddings via :predict

This is where the two Google surfaces diverge most. There is no :embedContent here — embeddings ride the generic prediction endpoint, in an envelope that looks nothing like AI Studio's.

// POST …/publishers/google/models/text-embedding-005:predict
{
  "instances": [{ "content": "hello", "task_type": "SEMANTIC_SIMILARITY" }],
  "parameters": { "outputDimensionality": 768 }   // per call, not per instance
}

{
  "predictions": [{
    "embeddings": {
      "values": [ /* … */ ],
      "statistics": { "truncated": false, "token_count": 2 }
    }
  }]
}

Note task_type and token_count in snake_case inside an otherwise camelCase API — that is the platform's own inconsistency, faithfully reproduced. countTokens here reports totalTokens and nothing else, where AI Studio's also breaks the count down by modality.

Gemini Enterprise · Interactions API

Served here too, on the same contract as AI Studio's — but reached through a path this platform builds oddly. In regional mode the SDK folds the entire version component, project and location included, into one percent-encoded path segment.

# express
/gemini-enterprise/v1beta1/interactions

# regional
/gemini-enterprise/v1beta1%2Fprojects%2F{project}%2Flocations%2F{location}/interactions

Both shapes reach the same handler. Everything else — steps, usage, streaming events, the stateless retrieval — behaves exactly as on the AI Studio surface.
